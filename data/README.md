# Geographic data

`africa.json` is derived from Natural Earth's 1:50m Admin 0 Countries dataset. It contains only features whose `CONTINENT` property is `Africa`, with properties reduced to `name` and `id`. Natural Earth data is in the public domain.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson
